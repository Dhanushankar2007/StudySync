# StudySync

StudySync is a study productivity platform designed to help students organize their learning and collaborate with others.

## Features

- Dashboard with study statistics
- Collaborative study rooms
- Study planner
- Learning resources
- Focus timer and study tracking
- Study analytics
- Notifications

## Tech Stack

- React
- Vite
- React Router

## Getting Started

1. Navigate to the frontend directory.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.

## Project Status

Frontend development in progress. Backend integration will be added later.
